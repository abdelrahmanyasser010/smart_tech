# FIX 365 — تصليح الأجهزة المنزلية بالكويت

موقع هبوط (Landing Page) لشركة **فيكس 365 (FIX 365)** المتخصصة في خدمات تصليح وتركيب الأجهزة المنزلية (تصليح غسالات، تصليح تكييفات، تصليح طباخات، تصليح ثلاجات، تصليح ديب فريزر) على مدار 24 ساعة في جميع مناطق الكويت.

---

## 🌟 مميزات المشروع

- **تصميم عصري ومتجاوب (Responsive Design):** متوافق بالكامل مع جميع الشاشات والهواتف الذكية.
- **دعم اللغة العربية والاتجاه (RTL):** خطوط عربية احترافية (Almarai و Tajawal).
- **تحويل سريع للعملاء (Conversion-Focused):** أزرار اتصال وواتساب مباشرة وشريط سفلي مخصص للهواتف.
- **أقسام متكاملة:**
  - قسم Hero مع سلايدر وصور عالية الجودة.
  - قسم من نحن وفريق العمل.
  - مجالات التصليح وخدماتنا.
  - إحصائيات سريعة بأرقام تفاعلية.
  - آراء وتقييمات العملاء.
  - معرض أعمال تفاعلي (Lightbox & Slider).
  - قسم الأسئلة الشائعة (FAQ).
  - خريطة الموقع ومعلومات التواصل.

---

## 🛠️ التقنيات المستخدمة

- HTML5 & CSS3
- Bootstrap 5
- Bootstrap Icons & Boxicons
- AOS (Animate On Scroll)
- Swiper JS
- GLightbox
